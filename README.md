# PyFlappyBird
Flappy Bird made in Python (PyGame)

## Installation

Install required libraries:
```bash
pip install pygame
pip install neat-python
pip install numpy
```

## Project Structure

- **FlappyBirdGame/** - Manual game (playable with SPACE)
- **FlappyBirdGameAI/** - AI training system (NEAT algorithm)
- **imgs/** - Game graphics (bird, pipes, background)

## Quick Start

### Play the game manually:
```bash
cd FlappyBirdGame
python flappy_bird_game.py
# Press SPACE to jump
```

### Train AI (recommended):
```bash
cd FlappyBirdGameAI
python train.py
```

### Test trained AI:
```bash
python test_ai.py
```

For detailed AI documentation, see [FlappyBirdGameAI/README.md](FlappyBirdGameAI/README.md)
